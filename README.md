# Android-Local-LLM

一个**完全离线**的安卓 AI 聊天 App：大语言模型下载到手机本地运行，对话不经过任何服务器，没有账号、没有网络请求（除了第一次下载模型）。

## 它能做什么

- 📥 **应用内下载模型**：内置 Qwen2.5 1.5B / Qwen3 0.6B 等中文模型，支持断点续传，下载完自动校验完整性
- 💬 **流式对话**：逐字输出回答，随时可以点停止
- 🗂 **多会话**：聊天历史保存在手机里，关掉 App 再打开，对话上下文还在
- 📁 **导入自己的模型**：手头有 `.gguf` 文件？直接从手机存储导入使用
- 🔒 **隐私**：所有推理都在本机完成，你的对话内容不会离开手机

## 安装

1. 到 [Releases 页面](https://github.com/renyouwumingda/Android-Local-LLM/releases) 下载最新的 `.apk` 文件
2. 传到手机上安装（需要允许「安装未知来源应用」）
3. 打开 App → 点右上角 ➕ 进入模型管理 → 下载一个模型（0.6B 约 378MB）→ 开始聊天

**要求**：Android 13 或更高，arm64 手机或 x86_64 模拟器。

> 当前发布的是 debug 签名版本，功能完整，适合个人使用；未做 release 签名，暂不上架应用商店。

## 常见问题

**模型下载很慢 / 失败？**
App 会自动切换到国内镜像重试。也可以从浏览器把 `.gguf` 文件下到手机，再用「从本地导入」功能。

**哪个模型适合我？**
- 内存 ≥ 4GB：Qwen2.5 1.5B（中文更好）
- 内存较小或想省空间：Qwen3 0.6B（378MB，够用）

**回答里带思考过程？**
不会。Qwen3 的思考块已自动过滤，只显示最终回答。
